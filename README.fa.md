# VPN Gate TUI — اسکنر سرور رایگان VPN Gate برای ایران

**زبان:** [English (پیش‌فرض)](README.md) | **فارسی (این صفحه)**

**دانلود کانفیگ رایگان OpenVPN، پیدا کردن سرورهای VPN Gate، تست پینگ VPN، بررسی SSTP و L2TP/IPsec و انتخاب سرور بر اساس کیفیت اتصال.**

VPN Gate TUI ابزار متن‌باز مبتنی بر Python و [Textual](https://textual.textualize.io/) است که فهرست سرورهای داوطلبانهٔ VPN Gate را از میرورهای روزانه جمع‌آوری می‌کند. این اسکنر برای کمک به کاربران ایرانی در **پیدا کردن سرور VPN Gate قابل‌دسترس از ایران**، **تست پینگ و پایداری OpenVPN** و **دریافت کانفیگ .ovpn** طراحی شده است.

**[دانلود برای ویندوز، لینوکس و مک](https://github.com/Trueness04/vpngate_tui/releases)** · [نصب از سورس](#نصب-از-سورس) · [کلیدهای میانبر](#کلیدهای-میانبر) · [English README](README.md)

> این پروژه سرور VPN ارائه نمی‌دهد. VPN Gate شبکه‌ای از سرورهای داوطلبانهٔ اشخاص ثالث است؛ فعال بودن سرورها، دسترسی از ایران، امنیت و حریم خصوصی تضمین نمی‌شود.

## قابلیت‌ها

- **پیدا کردن خودکار VPN Gate Mirror:** دریافت آدرس میرورهای روزانه از چند منبع، گردآوری موازی لیست سرورها و ادغام نتیجه‌ها.
- **بررسی OpenVPN TCP/UDP:** ارسال پروب پروتکل و اندازه‌گیری تأخیر پاسخ.
- **تست SSTP و L2TP/IPsec:** بررسی TLS/SSTP روی TCP/443 و پاسخ اولیهٔ IKEv1 روی UDP/500.
- **تست کیفیت سرور VPN:** محاسبهٔ Ping، Jitter، نرخ عدم پاسخ (Loss) و آزمون چندمرحله‌ای پایداری.
- **رتبه‌بندی مخصوص شرایط اینترنت ایران:** امتیاز تخمینی از پینگ، پایداری، سرعت اعلام‌شده، تعداد کاربران و ترکیب پورت و پروتکل.
- **تست واقعی OpenVPN:** تلاش برای اتصال با کلاینت OpenVPN نصب‌شده و تست اختیاری سرعت.
- **دانلود کانفیگ رایگان OpenVPN:** ذخیرهٔ فایل اصلی یا نسخهٔ تنظیم‌شده با timeout کوتاه‌تر، همچنین ذخیرهٔ ۱۰ کانفیگ برتر.
- **اتصال از ترمینال:** اتصال مستقیم به سرور منتخب یا تلاش خودکار برای اتصال به بهترین گزینه.
- **فیلتر و جست‌وجو:** کشور، IP، نام میزبان، TCP/443، OpenVPN، SSTP، L2TP، علاقه‌مندی و لیست سیاه.
- **تاریخچه و خروجی:** نگهداری نتایج در SQLite، استخراج CSV و JSON.
- **گزینه‌های دسترسی در شبکهٔ محدود:** پروکسی HTTP/SOCKS برای *دریافت لیست*، میرور سفارشی، بارگذاری CSV و فهرست جایگزین SSTP.

**دقت آزمون‌ها:** پاسخ IKE به معنی ورود موفق به L2TP/IPsec نیست؛ TLS موفق نیز SSTP را تأیید نمی‌کند. تست سریع OpenVPN جایگزین اتصال واقعی نیست. نتایج با توجه به ISP و زمان تغییر می‌کنند.

فایل را استخراج و **در ترمینال** اجرا کنید. ویندوز: `vpngate-tui.exe`؛ لینوکس یا مک: `./vpngate-tui` (در صورت نیاز `chmod +x vpngate-tui`). این‌ها اپلیکیشن‌های ترمینالی مستقل از نصب Python هستند، نه رابط گرافیکی دسکتاپ. انتشار فایل‌ها به موفقیت بیلد GitHub Actions بستگی دارد.

**نکته:** بخش‌های Connect، Auto-best و Deep Test به نصب جداگانهٔ برنامهٔ خط فرمان `openvpn` و مجوز لازم برای ساخت تونل نیاز دارند. برای اسکن و ذخیرهٔ کانفیگ OpenVPN لازم نیست.

## نصب از سورس

پیش‌نیاز: Python 3.10+ و ترمینال سازگار.

```bash
git clone https://github.com/Trueness04/vpngate_tui.git
cd vpngate_tui
python -m pip install -r requirements.txt
python vpngate_tui.py
```

در لینوکس می‌توانید از `python3` و در ویندوز از `py` استفاده کنید.

### استفاده از پروکسی، میرور و فایل CSV

```bash
python vpngate_tui.py --proxy socks5://127.0.0.1:1080
python vpngate_tui.py --mirror http://1.2.3.4:5555/
python vpngate_tui.py --import servers.csv
python vpngate_tui.py --out ./downloads
python vpngate_tui.py --help
```

گزینهٔ `--proxy` فقط درخواست‌های HTTP دریافت میرورها و سرورها را پروکسی می‌کند؛ تست مستقیم VPN و تونل OpenVPN از این مسیر عبور نمی‌کنند.

## کلیدهای میانبر

| کلید | عملکرد |
| --- | --- |
| `r` | تازه‌سازی فهرست سرورها |
| `t` | تست سریع سرورها |
| `u` | آزمون چندمرحله‌ای پایداری |
| `g` / `d` | تست عمیق بهترین‌ها / سرور منتخب |
| `a` | پیدا کردن و اتصال به بهترین سرور OpenVPN |
| `s` / `Ctrl+S` | ذخیرهٔ کانفیگ انتخابی / ده کانفیگ برتر |
| `/` | جست‌وجوی کشور، IP یا نام میزبان |
| `p` | تغییر فیلتر |
| `1` تا `5` | مرتب‌سازی امتیاز، پینگ، جیتر، سرعت یا کشور |
| `f` / `x` | علاقه‌مندی / لیست سیاه |
| `l` / `k` | مشخصات L2TP/IPsec / SSTP |
| `e` | خروجی CSV و JSON |
| `F2` | تغییر پوسته |
| `z` / `q` | توقف آزمون / خروج |
| `Enter` روی سرور | نمایش منوی عملیات |

## رفع مشکلات رایج

**چطور سرور رایگان OpenVPN برای ایران پیدا کنم؟** برنامه را اجرا کنید؛ پس از دریافت سرورها `t` را بزنید، بر اساس Ping یا Score مرتب کنید و با `s` فایل `.ovpn` را ذخیره کنید.

**هیچ سروری نمایش داده نمی‌شود؟** بعضی میرورها ممکن است مسدود یا غیرفعال باشند. از `--proxy`، `--mirror` یا `--import` استفاده کنید.

**سرور پیدا شده ولی اتصال برقرار نمی‌شود؟** وجود سرور در فهرست به معنی آماده بودن تونل VPN نیست. ابتدا تست سریع و سپس در صورت نصب OpenVPN تست عمیق `d` را اجرا کنید.

**فایل‌ها کجا ذخیره می‌شوند؟** کش، تنظیمات و تاریخچه به‌صورت پیش‌فرض در `~/.config/vpngate-tui/` قرار دارند؛ متغیر `VPNGATE_TUI_HOME` مسیر را تغییر می‌دهد. فایل‌های خروجی در Downloads یا `~/vpngate` ذخیره می‌شوند، مگر با `--out` مسیر تعیین کنید.

**آیا خود برنامه VPN است؟** خیر؛ ابزار کشف، بررسی و کمک به اتصال به سرورهای عمومی VPN Gate است.
